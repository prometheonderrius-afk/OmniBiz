## ElevateAI Integration Guide

This guide outlines how to build the recommended integrations for the above scenarios using the **ElevateAI** platform API and webhook workflows.

### 1. Web-Chat Assistant Setup (Scenarios A & B)
To capture leads 24/7 on the client's site, deploy the ElevateAI Web-Chat widget:
```html
<!-- ElevateAI Web-Chat Widget Widget -->
<script src="https://cdn.elevateai.com/widget/v1/chat.js" data-client-id="ELEVATE_CLIENT_ID"></script>
```
Customize the AI prompt to guide conversations toward capturing specific fields (Name, Phone, Email, Address, Inquiry Detail).

### 2. CRM Webhook Syncer (Scenarios B & C)
Configure an ElevateAI automation flow triggered on `chat.completed` or `form.submitted`. When triggered, send a POST request to the CRM endpoint (e.g. HubSpot, Jobber, or Salesforce Web-to-Lead):
```json
{
  "trigger": "chat.completed",
  "lead": {
    "first_name": "{{chat.lead_first_name}}",
    "last_name": "{{chat.lead_last_name}}",
    "email": "{{chat.lead_email}}",
    "phone": "{{chat.lead_phone}}",
    "address": "{{chat.lead_address}}",
    "notes": "{{chat.summary}}"
  }
}
```

### 3. Advanced Lead Enrichment (Scenario D)
For businesses with existing chat and CRM systems, run ElevateAI's conversation analysis on incoming chat transcripts. Query ElevateAI API for sentiment analysis and urgency scoring, then update the CRM record to alert high-priority agents:
```python
import requests

# Send transcript to ElevateAI for analysis
response = requests.post(
    "https://api.elevateai.com/v1/interactions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={
        "type": "chat",
        "transcript": "Customer transcript text..."
    }
)
result = response.json()
urgency_score = result.get("urgency_score") # 1-10
sentiment = result.get("sentiment") # Positive/Neutral/Negative
```
